# Rick and Morty Search Characters

App web para buscar personajes de Rick and Morty consumiendo la API oficial.

## Características

- Buscador de personajes en tiempo real
- Muestra nombre, imagen y estado del personaje
- Diseño responsivo con tema oscuro
- Animaciones en el título

## Uso

Simplemente abre `index.html` en tu navegador.

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- Rick and Morty API (https://rickandmortyapi.com/)
